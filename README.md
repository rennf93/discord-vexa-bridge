# CLA Signatures

This orphan branch stores CLA signatures for `discord-vexa-bridge`. It is managed
by the CLA Assistant action defined in `.github/workflows/cla.yml` on `master`;
contributors sign by posting the sign comment on their pull request, and the action
appends their record to `signatures/version1/cla.json`.

Do not edit `signatures/version1/cla.json` by hand.
